# Дипломный проект

## Автоматизация тестирования мобильного приложения «Мобильный хоспис»

### Описание проекта

Проект выполнен в рамках дипломной работы по профессии **«Инженер по тестированию»**.

В проекте реализованы UI-автотесты мобильного приложения **«Мобильный хоспис»** с использованием паттерна **Page Object**.

---

## Используемые технологии

- Kotlin
- Android Studio
- Espresso
- JUnit4
- Allure Framework
- Gradle

## Запуск проекта

1. Открыть проект в Android Studio.
2. Дождаться завершения синхронизации Gradle.
3. Запустить Android Emulator.
4. Собрать проект.

---

## Запуск автотестов

Автотесты можно запустить:

через Android Studio

```
Run → All Tests
```

или командой Gradle

```
./gradlew connectedAndroidTest
```

---

## Формирование Allure-отчета

После выполнения тестов необходимо получить результаты с устройства.

Для этого используется файл

```
allure-report.bat
```

После запуска автоматически:

- копируются результаты тестирования с эмулятора;
- создается папка `allure-results`;
- формируется HTML-отчет;
- открывается отчет Allure.
